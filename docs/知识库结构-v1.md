## 2. 检索流

```
用户局面
  → 机制识别（M1–M12）
  → 变体匹配（var-*，47 个）
  → 展开成员卡（西方模型 / 三十六计 / 变体统一动作）
  → 叠加原则（principle-*，20 条，定方向）
  → 输出：动作 + 反制 + 识别 + 伦理提示
```

原则卡与变体的关系：**原则定方向（道），变体选打法（术），成员卡给具体做法（术的变体）**。
