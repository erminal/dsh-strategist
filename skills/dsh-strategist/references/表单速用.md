# 表单速用（精简问法）

> 用 `ask_user_question` 时，每轮最多 2 个选择题 + 1 个自由输入题。
> 用户答“不确定”是合法输入。

## S1 目的（问 3 轮以内）

1. 这次你最想直接拿到什么？（拿到具体东西 / 阻止某事 / 维持关系 / 试探 / 退出 / 不确定）
2. 什么算“成了”，什么算“不可接受”？（各 1–3 条）
3. 你愿意为这件事牺牲多少关系？（0 一点不能伤 / 1 小摩擦 / 2 可以闹僵一部分 / 3 关系可以不要）
4. （自由输入）如果你也说不清目的：现在为什么想动？哪里最不舒服？

## S4 推演（问 2–3 轮）

1. 你有哪些动作？（2–4 个短句）
2. 对方可能怎么反应？（2–4 个短句，后面 T6 必须用这些原词）
3. 每个动作下，对方反应的概率大概多少？（可写“大概”，合计 100%）
4. 结果值 0–10（0 最差，10 最好；只用于比较）
5. （自由输入）你能接受的最差结果是什么？

## S6 转折（出现新信息时）

1. 发生了什么新情况？哪些确认、哪些听说？
2. 原来的目的还成立吗？（成立 / 要调整 / 不成立）
3. （自由输入）你现在最担心什么？

## 注意

- 不要一次把 10 个问题全抛给用户；
- 追问最多 5 条，按“影响 × 不确定 ÷ 成本”排序；
- 用户说“先这样”就停，输出条件式建议。
