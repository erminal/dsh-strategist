# 工具速查

项目根：包含 tools 与 kb 的目录（即本技能目录向上两级，按实际安装位置）

## 案例目录模板

```
tools/cases/<case>/
  background.txt
  goal.json
  sir.json
  game_input.json
  payoffs.json
  plans.json
  tree_spec.json
  decision.json
  report.html      # 渲染生成
```

## 命令

```bash
# 校验
python tools/check.py goal     tools/cases/<case>/goal.json
python tools/check.py sir      tools/cases/<case>/sir.json
python tools/check.py decision tools/cases/<case>/decision.json

# 结构/检索
python tools/t2_tag.py tools/cases/<case>/background.txt
python tools/t3_retrieve.py tools/cases/<case>/sir.json --top-k 5

# 推演
python tools/t4_build.py --sir tools/cases/<case>/sir.json \
  --me-actions "动作1|动作2|动作3" --opp-actions "反应1|反应2|反应3" \
  --payoffs tools/cases/<case>/payoffs.json --out tools/cases/<case>/game_spec.json
python tools/t5_solve.py expected --plans tools/cases/<case>/plans.json
python tools/t6_tree.py --game tools/cases/<case>/game_spec.json --tree tools/cases/<case>/tree_spec.json

# 安全/心性
python tools/t10_legal.py --text "..."
python tools/t11_mind.py --text "..."

# 日志
python tools/t8_log.py record --decision tools/cases/<case>/decision.json --session <case>
python tools/t8_log.py outcome --id N --result win --note "..."

# 一键链路 / 报告
python tools/run_pipeline.py --case tools/cases/<case> --out <输出目录>
python tools/render_report.py --case tools/cases/<case> --out tools/cases/<case>/report.html
```

## 输入文件最小结构

- `goal.json`：goal_id/type/ultimate/direct/success_criteria/unacceptable/non_goals/relationship_budget/time_window/constraints/confidence
- `sir.json`：schema_version/situation_id/round/goal/actors/facts/unknowns/structure/tags/completeness（<0.7 必须给 info_gaps）
- `game_input.json`：`{"me_actions":[...], "opp_actions":[...], "payoffs":"payoffs.json"}`
- `payoffs.json`：`[{"player":"A","action":"...","opp_action":"...","value":7,"source":"assumption"}]`
- `plans.json`：`{"plans":[{"name":"...","outcomes":[{"prob":0.5,"value":7}]}]}`
- `tree_spec.json`：`{"actions":[{"action":"...","reactions":[{"reaction":"...","prob":0.5,"payoff":7,"source":"assumption"}]}]}`
- `decision.json`：15 字段（见 check.py）

## 常见报错

| 报错 | 修法 |
|---|---|
| `缺少字段 xxx` | 补字段；看 check.py 顶部常量 |
| `完备度 < 0.7 时必须给 info_gaps` | 加 2–3 条追问清单 |
| `概率和不等于 1` | 调整概率 |
| `未知对方反应` | tree_spec 反应改用 Q2 原词（与 game_input 的 opp_actions 一致） |
| `未知卡 id` | `cards_used` 用 `var-*` / 模型卡 id，或删掉 |
| 法律 red | 换合法替代，禁止输出原方案 |
